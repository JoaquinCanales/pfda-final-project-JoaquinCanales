# Title
Running Rabbit

## Repository
https://github.com/JoaquinCanales/pfda-final-project-JoaquinCanales.git

## Description
A 2D autorunner in the vein of the Google dinosaur game where the player controls a rabbit who must jump over obstacles. Colliding with an obstacle will end the game.
## Features
- Obstacles
	- Obstacles will be hand drawn and then imported into the game and coded to act as the end of the game when touched by the player sprite.
- Looping Background
	- A background will be drawn where the left and right ends can seamlessly connect into a cohesive looping background. The background will then be imported and repeated to give the illusion of the character running through an environment.
- Running Rabbit Animation 
	- The rabbit will be animated in a few frames through Adobe Animate and then imported into the game as a gif.

## Challenges
- Figuring out how to add collision to the game's obstacles.
- Learning how to implement the jump feature of the main character.
- Deciding whether I can implement a looping animation to the player character sprite.

## Outcomes
Ideal Outcome:
- The ideal outcome is for the rabbit character to be able to jump over obstacles heading towards it, and touching an obstacle will end the game.

Minimal Viable Outcome:
- The bare essential would be for it to be a game involving avoiding obstacles.
